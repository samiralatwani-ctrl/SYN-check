# تجربة SYN على الهاتف (Expo Go) — دون حسابات مدفوعة

تحتاج: آيفون، وحاسوب Windows، وأن يكونا على **نفس شبكة الواي فاي**.

## أ) على الآيفون (مرة واحدة)
1. ثبّت تطبيق **Expo Go** من App Store (مجاني).

## ب) على الحاسوب (مرة واحدة)
1. ثبّت **Node.js** نسخة LTS من https://nodejs.org (اضغط Next حتى النهاية).
2. ثبّت **Git** من https://git-scm.com/download/win (اضغط Next حتى النهاية).
3. افتح **PowerShell** (ابحث عنه في قائمة ابدأ) واكتب الأوامر التالية، كل سطر على حدة:
   ```powershell
   cd $HOME\Desktop
   git clone https://github.com/samiralatwani-ctrl/lamber-lab
   cd lamber-lab
   git checkout syn/phase-1
   cd syn
   npm ci
   ```
   الأمر الأخير يستغرق بضع دقائق.

## ج) تشغيل التطبيق (في كل مرة)
1. في PowerShell:
   ```powershell
   cd $HOME\Desktop\lamber-lab\syn\apps\mobile
   npx expo start
   ```
2. يظهر **رمز QR** في النافذة. إن ظهر سطر يقول `Using development build`، اضغط حرف **s** للتحويل إلى **Expo Go**.
3. على الآيفون: افتح **الكاميرا** العادية ووجّهها إلى رمز QR، ثم اضغط الإشعار الذي يظهر، فيفتح التطبيق داخل Expo Go.
4. إن ظهرت رسالة "Allow access to local network"، اختر **السماح**.
5. أول فتح يستغرق نحو دقيقة.

**إن لم يتصل الهاتف بالحاسوب** (شبكات العمل والفنادق تمنع ذلك أحياناً)، أوقف التشغيل بـ `Ctrl+C` ثم شغّل:
```powershell
npx expo start --tunnel
```

افتح في متصفح الحاسوب الملف `syn\docs\testing\kit\index.html`، وامسح منه بالهاتف.

## هـ) ما ترسله لي
لكل سيناريو اكتب ✓ أو ✗، مع لقطة شاشة لأي خطأ أو نص غير واضح أو اتجاه مقلوب. ولاحظ أيضاً:
- سرعة قراءة الملصق.
- وضوح الخط العربي.
- هل نصوص النتائج مفهومة لمستخدم عادي.
